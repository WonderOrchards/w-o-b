# Observations

This is the append-friendly record of what is noticed in the real world: trees, plants, experiments, weather, harvests, failures, photographs, discoveries, and other orchard reality.

An observation records experience. It does not automatically establish a general conclusion, policy, or decision.

## Add an Observation

Add the newest entry at the top of the log using only the fields that help:

```markdown
## YYYY-MM-DD — Subject

- **What was noticed:**
- **Action:** None | what was done in response
- **Outcome:** Unknown | what happened afterward
- **Related:** [Experiment or document](path)
- **Photographs:** None | links or safe repository paths
```

If the outcome is not yet known, write `Unknown`. Return to the same entry when a later observation establishes it, or add a new dated observation and link the two.
