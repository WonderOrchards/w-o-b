# Wonder Orchards Database – Micro Header

All new entries in this thread must be formatted in the Wonder Orchards database style:

- Use `# --- FILE: path/to/file.md ---` at the top.  
- Follow with YAML frontmatter enclosed in `---` blocks, containing:  
  - title  
  - status  
  - tags  
  - last_updated  
- Body in Markdown with clear sections or bullet lists.  
- Infer reasonable status, tags, filenames, and dates if not specified.  
- Return the entire entry in **one clean, copy-pastable block** (no extra commentary).  

### Example

# --- FILE: folder/entry-name.md ---
---
title: "Entry Title"
status: in_progress
tags: [example, tags]
last_updated: 2025-09-06
---
